# Neon Arena FPS

A complete browser-based 3D arena shooter built with Three.js.

## Play

Open `index.html` in a modern browser, or serve the folder with:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Controls

- **WASD** — Move
- **Mouse** — Aim
- **Left click** — Fire
- **R** — Reload
- **1 / 2 / 3** — Switch weapons
- **Shift** — Sprint
- **Esc** — Release mouse

## Weapons

- Assault rifle — 30-round magazine
- Shotgun — 8-round magazine with spread
- Pistol — 12-round magazine
